# 📝 Mini Messageboard

A simple messageboard application built with Express.js and EJS as the template engine.
Users can create new messages, view all messages, and open a dedicated details page for each message.
The project uses ES Modules and separates routes, views, message data, and helper functions into dedicated modules.
Nodemon is included as a development dependency to automatically restart the server when files are changed.
The application uses only in-memory data storage, so messages are reset whenever the server is restarted.
